# Sparkform

A creative, pixel-perfect single landing page focusing on an interactive Hero section. It features a stunning 3D character bust overlapping vibrant typography with stacked text drop-shadow effects, as well as a continuous marquee.

## 🚀 Tech Stack

- React
- TypeScript
- Tailwind CSS
- Vite

## 🛠 Features

- Scroll-driven animations updating text positions in real-time.
- Layered typography with specific Z-indices to create a retro 3D stacked effect.
- An infinite CSS-based marquee loop.
- Interlocking z-order structure integrating image overlapping with text.
