# Talent Collective

A single full-viewport React page for a creative studio called "Kollektiva". It renders a seamless, interactive fullscreen gallery of team members using absolutely positioned background images and CSS opacity transitions.

## 🚀 Tech Stack

- React 18
- TypeScript
- Tailwind CSS 3
- Vite

## 🛠 Features

- Full-bleed stacked background portraits transitioning seamlessly on avatar selection.
- Responsive design tailored for mobile, tablet, and desktop views with specific avatar configurations.
- Minimalist typography-focused layout using the Geist font.
- Pure CSS keyframe animations for content entry transitions.
