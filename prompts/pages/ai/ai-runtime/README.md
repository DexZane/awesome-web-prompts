# AI Runtime

A single-viewport, full-bleed video-background landing page for an enterprise AI platform ("Intelligence Designed To Evolve"). Built with pure HTML5, CSS3, and vanilla JS, showcasing retro dot-matrix display typography, interactive navigation pills, brand trust badges, and animated stat counters.

## 🚀 Tech Stack

- HTML5
- CSS3 (Vanilla CSS variables & animations)
- Vanilla JavaScript
- Font Awesome 6.5.2

## 🛠 Features

- Full-bleed looping CloudFront video background with dark fallback.
- Bubbledot / Geist Pixel dot-matrix display typography.
- Enterprise trust badges with overlapping avatar rings and icon brands.
- Interactive white nav pill with three-dot active indicator and mobile drawer sheet.
- Counting stats footer with tabular-nums and easeOutCubic JS animation.
