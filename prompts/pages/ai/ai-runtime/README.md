# AI Runtime

A single-viewport, full-bleed video-background landing page for an enterprise AI platform ("Intelligence Designed To Evolve"). Built with pure HTML5, CSS3, and vanilla JS, showcasing retro dot-matrix display typography, interactive navigation pills, brand trust badges, and animated stat counters.

## 🚀 Tech Stack
