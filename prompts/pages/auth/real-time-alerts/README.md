# Real-Time Alerts (Signal)

A self-contained, single-file HTML/CSS/JS login page reconstructed with pixel precision from a 1464×949 design specification. Features a looping falcon dive video, bespoke typography tokens, base64 font fallbacks, a custom 3-mode responsive engine (`land`, `tabport`, `phone`), and a choreographed Web Animations API (WAAPI) timeline.

## 🚀 Tech Stack

- Vanilla HTML5 (self-contained inline CSS & JS)
- Vanilla CSS3 (custom properties, fluid math & variable font axes)
- Vanilla JavaScript (Responsive mode engine & WAAPI orchestration)

## 🛠 Features

- **Self-contained**: Single static HTML file with all inline CSS, SVGs, and scripts.
- **Falcon Video Hero**: Responsive video background covering desktop split view and mobile masthead.
- **Three-Mode Responsive Engine**: Continuous scaling for landscape (`land`), adaptive masthead + fluid form for tablet portrait (`tabport`), and natural document-flow layout for mobile phones (`phone`).
- **Precision WAAPI Timeline**: Web Animations API sequence orchestrating depth, brand badges, and functional inputs with reduced-motion support.
- **A11y & Form Calibrations**: Complete accessibility attributes, no iOS zoom triggers, and intentional optical alignment tokens.
