# VaultShield Hero

A responsive fullscreen hero section for a password manager app called "VaultShield". It features a background video, Framer Motion staggered load animations, Lucide React icons, and a slide-in mobile menu.

## 🚀 Tech Stack

- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React
